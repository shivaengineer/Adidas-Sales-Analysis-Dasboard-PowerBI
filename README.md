# Adidas Sales Analysis Dashboard

## Project Overview

This project presents an interactive sales analysis dashboard created using Microsoft Power BI. It helps analyze Adidas sales performance across different months, regions, products, states, and retailers.

## Dashboard Preview

![Adidas Sales Analysis Dashboard](images/dashboard_preview.png)
---
## Objectives

- Analyze overall sales and profit performance.
- Track monthly sales trends.
- Compare sales across regions and states.
- Identify top-performing product categories.
- Compare retailer-wise sales performance.
- Explore sales by year and sales channel.
---
## Dashboard Features

- **KPI Cards:** Total Profit, Total Sales, Total Units Sold, Average Price per Unit, and Profit Margin.
- **Monthly Sales Trend:** Visualizes sales performance from January to December.
- **State-wise Sales:** Displays geographical sales distribution across the United States.
- **Region-wise Sales:** Compares sales across different regions.
- **Product-wise Sales:** Highlights sales by product category.
- **Retailer-wise Sales:** Compares sales across retailers.
- **Interactive Filters:** Includes year, sales channel, and month selections.

## How to Use

1. Clone or download this repository.
2. Install Microsoft Power BI Desktop.
3. Open `dashboard/adidas_sales_dashboard.pbix`.
4. If prompted, update the data source path to match your local files.
5. Refresh the data, if required, to explore the dashboard.
